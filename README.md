# খড়্গ

বাংলার মুসলিম শাসনের ইতিহাস শেখানো একটা **ব্রাউজার-খেলার লড়াই-গেম** — ১২০৪ (নদিয়ার পতন)
থেকে ১৭৫৭ (পলাশী) পর্যন্ত, ৯টি অধ্যায়। পুরো ইন্টারফেস বাংলায়, কোনো সার্ভার লাগে না
(GitHub Pages-এ সরাসরি চলে), আর আঘাতে রক্ত পড়ে না — লড়াইয়ের লক্ষ্য কাউকে মারা নয়,
নৌকা/ধান/গ্রাম রক্ষা করা।

আপনি কোনো সুলতান নন। আপনি একই অজ্ঞাত কারিগরের বানানো খড়্গের ধারক-বংশ —
প্রতি অধ্যায়ে হাত বদলায়, তাই সাড়ে পাঁচশো বছর ধরে থাকা সম্ভব।

## চালানো

```bash
npm ci
npm run check          # validate → typecheck → test → build → preview
python3 -m http.server 8124 --directory docs   # অথবা: npm run serve
```

ব্রাউজারে <http://localhost:8124> খুলুন। কোনো বিল্ড-স্টেপ ছাড়াই `file://` দিয়েও
`docs/content-preview.html` খোলে (ওটা খেলা নয়, সমগ্রী-পড়ার পাতা)।

## নিয়ন্ত্রণ (মোবাইল ও ডেস্কটপে একই ৬টি ইনপুট)

| ইনপুট | কাজ | কিবোর্ড | টাচ |
|---|---|---|---|
| কাটা | দ্রুত, হালকা | `J` | ১ |
| কোপ | ধীর, ভারী, ঢাল ভাঙে | `K` | ২ |
| পোঁতা | সবচেয়ে লম্বা পাল্লা | `L` | ৩ |
| রোধ / প্রতিউত্তর | ৮-ফ্রেম নিখুঁত জানালা | `Space` | ৪ |
| সবে | ১০ ফ্রেম অছোয়া | `Shift` | ৫ / সোয়াইপ |
| সংকল্প | চরম আঘাত (মিটার ১০০ লাগে) | `U` | ৬ |

চলাফেরা: অ্যারো / `WASD`, মোবাইলে বাম পাশের ভার্চুয়াল স্টিচ। প্রশ্নের উত্তর `১–৪`।

## গঠন

```
content/chapters.json   # সমস্ত ইতিহাস: ৯০ কার্ড, ৩৫ প্রশ্ন — একমাত্র সত্য-উৎস
content/schema.json     # রূপ + প্রতিটি নিয়মের কারণ
tools/validate.mjs      # উৎসবিহীন দাবি / একপক্ষ-মত / লিপি-লিকেজ → বিল্ড ফেল
tools/build.mjs         # esbuild + ফন্ট সাবসেটিং + SW → docs/
src/frames.ts           # ফ্রেম-ডেটা (টেস্টে আটকানো)
src/fighter.ts          # state machine — DOM/Canvas/Date.now()/random-মুক্ত
src/sim.ts              # ঢেউ (রক্ষা) + দ্বন্দ্ব (ঢাল ভাঙো + ৩ সত্য)
src/render.ts           # ছায়া-পুতুল রেন্ডারার
docs/design-khadga.md   # নকশা-ব্রিফ ও সিদ্ধান্ত-রেকর্ড
```

**নীতি:** কোনো ইতিহাস-দাবি কোডে লেখা নয় — সব `content/chapters.json`-এ, এবং প্রতিটি
কার্ডে উৎস বাধ্যতামূলক। মতভেদের ১১টি কার্ডে দুই পক্ষই দেখানো হয়। `npm run validate`
না চললে বিল্ড ওঠে না।
